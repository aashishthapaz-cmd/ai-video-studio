# 🎬 Zero-Cost Cloud Video Studio & Auto Facebook Publisher

A 100% cloud-hosted video creation and distribution system that renders 1080x1920 portrait videos with human-grade voice cloning, 2.5D parallax animations, cinematic overlays, and publishes directly to multiple Facebook Pages.

## ✨ Features
* **Zero GPU Requirement**: Runs entirely on cloud APIs (Pollinations, Cloudflare, Hugging Face, Edge Neural TTS, XTTS-v2).
* **Human Voice Cloning**: Clones reference audio (`whishper.wav`) with deep, warm, intimate poetry cadence.
* **Fine-Art Visuals**: 25+ aesthetic world rotation (Ghibli, Makoto Shinkai, Ukiyo-e, Bioluminescent, Anime).
* **Exact 2.5D Parallax Motion**: Multi-layer foreground/background depth animations with quintic smootherstep camera moves.
* **Cinematic Dust & Overlays**: Integrated 0.15 opacity video overlays and ambient music mixing.
* **Multi-Page Facebook Publisher**: Direct Graph API v20.0 publishing for Facebook Reels & Videos.

## 🚀 Running Locally or in Hugging Face Spaces
1. Create a Free Space on Hugging Face (`sdk: docker`).
2. Push this repository to your Space.
3. Access your studio anytime from your browser or mobile phone!
